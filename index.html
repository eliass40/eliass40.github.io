    How to drive it

    Type
    Fills the current answer, letters and digits both work
    Enter
    Checks the answer, or moves on if it is solved
    ↑ ↓
    Previous or next clue (Page Up and Page Down also work, so a presentation clicker does too)
    ← →
    Moves between squares in the answer
    Backspace
    Deletes a letter
    Click
    Any square, message tile or listed clue jumps to that clue
    Show all clues
    Top right: switches between one clue at a time and the full list
    ?
    Opens this list, Esc closes it

    Progress is saved in this browser, so a reload picks up where you left off. Start over clears everything.
